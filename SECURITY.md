# Garage OS Security Policy

This is a business-operations application. Public repository access does not authorize testing production systems or accessing operational data.

## Report vulnerabilities privately

Use GitHub's private vulnerability reporting under **Security → Report a vulnerability**, if enabled. Otherwise, contact the maintainer through an established private channel. Do not disclose vulnerabilities, passwords, production endpoints, employee details, or transaction data in public issues or pull requests.

## Safe testing

Only test in a local or explicitly authorized sandbox with synthetic data. Do not probe Garage Coffee production services, accounts, APIs, financial data, payment interfaces, or third-party integrations.

## Release status

The repository is undergoing a public-release safety review. No statement of full security assurance, complete historical secret scanning, or general-purpose open-source licensing is made by this policy.

This policy does not guarantee a response or remediation schedule.
