# Panduan Absen — Karyawan Garage

## Aturan Sederhana

**Absen masuk + keluar lengkap = gaji harian + fee pool masuk wallet.**
**Tidak absen lengkap = Rp 0.**

## Cara Absen (HP kamu)

1. Buka `https://app.garagecoffee.id/absen`
2. Login dengan akun Garage
3. Tekan **[BUKA KAMERA DEPAN]** → foto wajah
4. Masukkan **PIN 6 digit** kamu
5. Tekan **[ABSEN MASUK]** — otomatis ganti jadi **[ABSEN KELUAR]** saat pulang

## Syarat Wajib

- ✅ PIN benar
- ✅ Selfie (wajah kelihatan)
- ✅ GPS aktif + jarak toko < 50 meter
- ✅ Checkout minimal jam 22:30 (closing normal 23:00)

## Wallet Kamu

- **`/staff/wallet-gaji`** — saldo upah harian (chrome) → hasil dari upah × bracket telat + lembur
- **`/staff/wallet-fee`** — saldo fee pool (amber) → bagian kamu dari Rp 200 × produk hari itu

Fee dibagi berdasarkan **jam kerja kamu vs total jam tim**. Kalau kamu jaga sendirian → dapat 100%.

## Aturan Telat

| Datang | Upah |
|---|---|
| Tepat / ≤ 09:15 | 100% |
| 09:16 – 10:00 | 75% |
| 10:01 – 11:00 | 50% |
| > 11:00 | Absent (Rp 0) |

## Cair Gaji

- Tekan **[Cairkan]** di wallet → pilih jumlah + alasan → tunggu owner approve
- Setelah approve → status "Paid" → uang siap ditransfer/tunai

## Tidak Boleh

- ❌ Titip absen (selfie orang lain terdeteksi)
- ❌ Absen dari luar toko (GPS di luar radius)
- ❌ Lupa checkout (status invalid → Rp 0)

Kalau ada masalah PIN / GPS error → lapor Supervisor.
