## 11. Keputusan Besok

Pilih satu:

- [ ] `GO`: lanjut campaign/operasional normal.
- [ ] `CONDITIONAL`: lanjut terbatas dengan fix wajib.
- [ ] `NO-GO`: tahan campaign, fokus fix operasional.

Keputusan:

```txt

Alasan:
Fix wajib sebelum buka:

Promo yang stop:
```
