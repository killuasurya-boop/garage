# GARAGE Google Maps Local SEO Checklist

Google Maps adalah landing page kedua GARAGE. Banyak customer coffee shop lokal memutuskan datang dari Maps sebelum membuka website, jadi profile harus rapi sebelum campaign dibesarkan.

## 1. Profile Foundation

- [ ] Nama bisnis final: `GARAGE Coffee` atau nama resmi outlet yang dipakai di signage.
- [ ] Kategori utama dipilih: coffee shop/cafe sesuai ketersediaan Google Business Profile.
- [ ] Kategori tambahan dipilih hanya jika benar tersedia.
- [ ] Alamat final sesuai lokasi outlet.
- [ ] Pin map dicek dari HP customer.
- [ ] Nomor WhatsApp/telepon aktif.
- [ ] Website mengarah ke landing page final.
- [ ] Jam buka final.
- [ ] Jam khusus/libur diisi jika ada.
- [ ] Deskripsi bisnis singkat, natural, dan tidak berlebihan.

Template deskripsi:

```txt
GARAGE Coffee adalah tempat ngopi harian untuk coffee, snack, takeaway, dan kerja ringan. Lihat menu, cek lokasi, atau pesan melalui WhatsApp sebelum datang.
```

## 2. Foto Wajib

Upload foto nyata, terang, dan konsisten dengan brand. Jangan gunakan foto brand lain.

- [ ] Exterior dari jalan.
- [ ] Signage/pintu masuk.
- [ ] Area kasir/coffee bar.
- [ ] Area duduk.
- [ ] Work spot/table scene.
- [ ] 3 foto signature drink.
- [ ] 3 foto food/snack.
- [ ] 1 foto packaging takeaway.
- [ ] 1 foto staff/barista.
- [ ] 1 foto QR/meja jika dine-in memakai QR order.
- [ ] 1 foto promo/menu board jika tersedia.
- [ ] 1 foto akses parkir jika relevan.

Standar foto:

- [ ] Tidak blur.
- [ ] Tidak terlalu gelap.
- [ ] Tidak ada brand kompetitor yang dominan.
- [ ] Tidak ada data customer pribadi.
- [ ] Produk terlihat jelas.
- [ ] Rasio aman untuk crop Google Maps.

## 3. Menu dan Produk

- [ ] 3 menu signature masuk profile.
- [ ] Harga sesuai POS dan landing page.
- [ ] Menu out-of-stock tidak dipromosikan.
- [ ] Promo hanya dimasukkan jika periode aktif jelas.
- [ ] Foto menu memakai aset GARAGE.
- [ ] Deskripsi menu singkat dan tidak klaim palsu.

## 4. Review Engine

Target awal: 30 review nyata dalam 30 hari.

- [ ] Link review Google Maps dibuat.
- [ ] QR/link review ditempel di kasir atau dikirim setelah order.
- [ ] Staff tahu kapan meminta review: setelah order selesai dan customer puas.
- [ ] Template minta review tersedia.
- [ ] Template balas review positif tersedia.
- [ ] Template balas review negatif tersedia.
- [ ] Review dicek setiap hari.
- [ ] Review negatif dibalas maksimal 24 jam.

Template minta review:

```txt
Terima kasih sudah mampir ke GARAGE Coffee.

Kalau pengalaman kamu oke, bantu kami dengan review di Google Maps ya:
{link review}

Review kamu membantu orang lain menemukan GARAGE.
```

Template review positif:

```txt
Terima kasih sudah mampir ke GARAGE Coffee. Senang sekali kamu menikmati pengalaman di sini. Sampai ketemu lagi.
```

Template review negatif:

```txt
Terima kasih sudah memberi tahu kami. Mohon maaf pengalaman kamu belum sesuai harapan. Kami akan cek detailnya dan memperbaiki alur layanan kami.
```

## 5. Google Maps Post

Ritme: 1 post per minggu.

| Minggu | Topik | Asset | CTA |
| --- | --- | --- | --- |
| 1 | GARAGE Coffee daily coffee + work spot | Foto exterior/interior | Buka Maps |
| 2 | Signature drink | Foto produk | Lihat Menu |
| 3 | Morning/work break promo | Foto paket | Pesan WA |
| 4 | Review/customer moment | Foto suasana | Mampir Hari Ini |

Aturan post:

- [ ] Pakai satu pesan utama.
- [ ] CTA jelas.
- [ ] Jangan publish promo sebelum staff/POS siap.
- [ ] Jangan pakai harga jika belum final.
- [ ] Jangan gunakan foto stok generik.

## 6. Local SEO Keyword

Gunakan keyword natural, bukan spam.

- [ ] coffee shop di area outlet.
- [ ] tempat ngopi.
- [ ] cafe untuk kerja ringan.
- [ ] takeaway coffee.
- [ ] menu coffee dan snack.
- [ ] lokasi dekat landmark sekitar jika benar.

Keyword harus masuk secara natural di:

- [ ] Deskripsi Google Maps.
- [ ] Landing page.
- [ ] Caption Instagram.
- [ ] Google Maps posts.

## 7. Maps Smoke Test

Lakukan dari HP customer, bukan hanya laptop admin.

- [ ] Cari nama GARAGE di Google Maps.
- [ ] Pin lokasi benar.
- [ ] Klik arah/rute berhasil.
- [ ] Klik telepon/WhatsApp berhasil.
- [ ] Klik website berhasil.
- [ ] Jam buka tampil benar.
- [ ] Foto utama tidak salah crop.
- [ ] Customer bisa paham cara datang/order dalam < 30 detik.

## 9. Go / No-Go Google Maps

GO jika:

- [ ] Profile lengkap.
- [ ] Alamat, jam, nomor, website benar.
- [ ] Foto utama nyata dan layak.
- [ ] Link Maps dan review siap.
- [ ] Staff tahu cara meminta review.
- [ ] Google Maps mengarah ke landing page/WA yang siap.

NO-GO jika:

- [ ] Pin lokasi salah.
- [ ] Jam buka salah.
- [ ] Nomor WA salah.
- [ ] Foto bukan aset GARAGE.
- [ ] Promo di Maps tidak sesuai POS.
- [ ] Review negatif tidak punya owner.
