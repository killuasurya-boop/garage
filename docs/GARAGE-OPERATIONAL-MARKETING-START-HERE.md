# GARAGE Operational Marketing Start Here

Mulai dari file ini saat GARAGE ingin siap operasional dan siap dipasarkan. File ini bukan checklist detail; ini runbook urutan kerja agar owner, operasional, marketing, dan developer membuka dokumen yang benar pada waktu yang benar.

## 1. Prinsip Keputusan

Jangan scale marketing sebelum tiga hal terbukti:

- Operasional bisa menerima order tanpa kacau.
- Marketing channel mengarah ke CTA yang benar.
- Owner bisa melihat angka harian dan memutuskan lanjut, batasi, atau stop.

Status akhir yang dicari bukan "dokumen lengkap", tetapi:

```txt
GARAGE siap menerima traffic, order, payment, produksi, komplain, review, dan repeat customer dengan alur yang terbukti.
```

## 3. Fase Eksekusi

### Fase A: Kunci Arah Jualan

Owner dan marketing membuka:

- `docs/GARAGE-OPERATIONAL-MARKETING-CHECKLIST.md`
- `docs/GARAGE-PROMO-PROFIT-WORKSHEET.md`

Output wajib:

- [ ] Positioning utama dipilih.
- [ ] 3 menu signature dipilih.
- [ ] HPP/base cost diketahui.
- [ ] Promo awal dihitung margin.
- [ ] Promo yang belum aman ditahan.

Status naik jika:

- `Promo Profit` minimal `Margin OK`.
- Owner approve menu dan promo.

### Fase B: Siapkan Channel Customer

Marketing dan kasir membuka:

- `docs/GARAGE-WHATSAPP-ORDER-SOP.md`
- `docs/GARAGE-GOOGLE-MAPS-LOCAL-SEO-CHECKLIST.md`
- `docs/GARAGE-MARKETING-30-DAY-CONTENT-CALENDAR.md`

Output wajib:

- [ ] WA Business lengkap.
- [ ] Template WA order/payment/ready/komplain siap.
- [ ] Google Maps benar: alamat, jam, nomor, foto, website.
- [ ] Link review Google Maps siap.
- [ ] Kalender konten 30 hari siap.
- [ ] Semua konten promo mengacu ke worksheet margin.

Status naik jika:

- WA order lulus test chat.
- Maps lulus smoke test dari HP.
- CTA landing page/WA/Maps tidak rusak.

### Fase C: Training dan Simulasi Shift

Manager operasional membuka:

- `docs/GARAGE-STAFF-SOFT-LAUNCH-TRAINING-CHECKLIST.md`
- `docs/SOP-FINAL-OPERASIONAL-GARAGE.md`
- `docs/garage-qr-cashier-sop.md`

Output wajib:

- [ ] Owner/manager lulus skenario dashboard dan issue review.
- [ ] Kasir lulus POS, QR, WA, promo, payment, closing.
- [ ] Kitchen/barista lulus ticket/status/item kosong.
- [ ] Marketing lulus WA/Maps/content/review flow.
- [ ] Semua issue dicatat di `docs/PILOT-ISSUE-LOG.md`.

Status naik jika:

- Role kritis `Pass`: owner/manager, kasir, kitchen/barista, marketing/WA.
- Tidak ada P0/P1 terbuka.

### Fase D: Soft Launch 14 Hari

Owner, manager, dan marketing membuka:

- `docs/GARAGE-OPERATIONAL-MARKETING-CHECKLIST.md`
- `docs/GARAGE-DAILY-OWNER-REPORT-TEMPLATE.md`
- `docs/PILOT-ISSUE-LOG.md`

Output wajib setiap hari:

- [ ] Laporan owner harian terisi.
- [ ] Issue P0/P1/P2 dicatat.
- [ ] Promo direview: continue, adjust, stop.
- [ ] Konten yang publish sesuai status operasional.
- [ ] Keputusan besok: GO, CONDITIONAL, atau NO-GO.

Status naik jika:

- Minimal 3 hari berturut-turut tidak ada P0/P1.
- Closing harian bisa dibaca owner.
- WA, QR, walk-in, promo order berjalan.
- Staff tidak perlu owner turun tangan terus untuk flow normal.

## 4. GO / CONDITIONAL / NO-GO

### GO

Campaign boleh jalan normal jika:

- [ ] Landing page CTA berjalan.
- [ ] Google Maps benar.
- [ ] WA order siap.
- [ ] POS/QR/payment stabil.
- [ ] Promo margin aman.
- [ ] Staff lulus simulasi.
- [ ] Daily owner report terisi.
- [ ] Tidak ada P0/P1 terbuka.

### CONDITIONAL

Campaign boleh jalan terbatas jika:

- [ ] Ada P2/P3, tetapi workaround jelas.
- [ ] Promo dibatasi jam/item/channel.
- [ ] Owner/manager standby.
- [ ] Fix target maksimal 24 jam.

### NO-GO

Tahan campaign jika:

- [ ] POS/QR/payment tidak stabil.
- [ ] WA mengarah ke nomor yang belum siap.
- [ ] Maps salah alamat/jam/nomor.
- [ ] Staff belum lulus skenario kritis.
- [ ] Promo belum dihitung margin.
- [ ] Owner tidak menerima laporan closing.

## 5. Daily Ritual

### Sebelum Buka

- [ ] Cek menu kosong.
- [ ] Cek promo aktif.
- [ ] Cek WA/Maps/landing CTA.
- [ ] Brief staff.
- [ ] Cek issue kemarin yang belum selesai.

### Saat Operasional

- [ ] Pantau order walk-in, QR, WA.
- [ ] Catat komplain.
- [ ] Catat stok kritis.
- [ ] Jangan publish konten promo jika operasional sedang bermasalah.

### Closing

- [ ] Isi `docs/GARAGE-DAILY-OWNER-REPORT-TEMPLATE.md`.
- [ ] Update `docs/PILOT-ISSUE-LOG.md`.
- [ ] Putuskan GO/CONDITIONAL/NO-GO untuk besok.
- [ ] Tentukan konten yang boleh publish besok.

## 6. Evidence Minimum

Status checklist boleh naik hanya dengan evidence berikut:

| Area | Evidence Minimum |
| --- | --- |
| Landing page | Screenshot desktop/mobile + CTA test |
| WhatsApp | Screenshot test chat order + payment/ready template |
| Google Maps | Screenshot profile dari HP + link Maps/review |
| Promo | Worksheet margin + owner approval + POS test |
| Staff | Training sign-off + simulation result |
| POS/QR | Smoke test walk-in, QR, WA, promo, closing |
| Dashboard | Daily owner report dari data closing |

## 7. File yang Harus Diupdate Saat Eksekusi

- `docs/GARAGE-OPERATIONAL-MARKETING-CHECKLIST.md`: status master.
- `docs/PILOT-ISSUE-LOG.md`: semua issue saat pilot/soft launch.
- `docs/GARAGE-DAILY-OWNER-REPORT-TEMPLATE.md`: salin per hari atau isi sebagai template harian.
- `docs/GARAGE-PROMO-PROFIT-WORKSHEET.md`: promo dan margin.
- `docs/GARAGE-STAFF-SOFT-LAUNCH-TRAINING-CHECKLIST.md`: sign-off staff.

## 8. Catatan Penting

- Dokumen ini belum menyatakan GARAGE sudah GO.
- Semua status awal tetap draft sampai diverifikasi dengan bukti nyata.
- Jika ada perubahan harga, jam buka, nomor WA, atau promo, update semua channel: POS, landing page, WA, Google Maps, dan konten.
