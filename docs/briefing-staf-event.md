## KASIR
1. POS → tombol **Paket Event** → tap paket → pilih minuman (tombol **Hot / Cold**) & cemilan → **Tambah paket**.
2. Take away: isi **nama pelanggan**. Dine-in: isi **nomor meja**. Centang "Sertakan isi keranjang" bila tamu juga pesan menu biasa.
3. **Simpan & Final Bayar** → pilih Tunai/QRIS → **Konfirmasi Bayar**.
4. Lihat kotak kuning **"Serahkan langsung: 1× Black Matcha"** → serahkan rokok dari laci. **Minta KTP bila tamu tampak di bawah 21 tahun.** Tidak boleh jual rokok ke tamu di bawah 21.
5. Pesanan paket dari QR/HP tamu masuk ke **Pesanan Pelanggan** seperti biasa → Terima → Final Bayar (kotak "Serahkan langsung" juga muncul).
6. Batal/refund paket harus **satu paket utuh** (tidak bisa refund rokoknya saja).
7. Tombol Paket Event tidak muncul / "gagal dimuat" → tekan **Coba lagi**. Masih gagal: hubungi manajer; sementara jual komponen satuan + diskon manual sampai total = harga paket.

## BAR / DAPUR
- Tiket bertanda **"Paket: Bundling …"** = minuman & cemilan satu pesanan. Cocokkan lewat **nomor order / nama tamu** saat antar.
- Rokok **tidak** masuk tiket Bar/Dapur (diserahkan kasir).
- Hot = tanpa es batu.

## WAITER
- Paket **tidak** bisa diinput dari mode waiter. Arahkan tamu ke **kasir** atau **scan QR meja** (paket ada di bagian atas menu).

## MANAJER
- Awal & akhir shift: **hitung stok rokok manual** (rokok tidak terpotong otomatis di gudang).
- Event → tab Laporan: penjualan per paket & **sisa kuota** (rentang otomatis = tanggal acara).
- Acara molor → perpanjang **jam selesai event**; paket ikut diperpanjang otomatis.
