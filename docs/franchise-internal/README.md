# Bahan internal franchise (bukan untuk publik)

Dipindah dari `public/franchise-site/uploads/` (audit website, 8 Nov 2026): semua yang ada di `public/` bisa diunduh
siapa saja lewat `/franchise-site/uploads/...`. Folder ini berisi SOP, konsep fee karyawan, runbook LAN, koleksi Postman
dan dokumentasi aplikasi (termasuk contoh password seed) — tidak dipakai halaman mana pun.

Jangan taruh dokumen internal di `public/`. Bila salah satu password/kunci contoh di sini pernah dipakai di produksi,
ganti di server.
