# Panduan Kurir Delivery

> Mengambil pesanan delivery yang sudah lunas, mengantar dengan GPS, dan menyelesaikan dengan foto bukti.
>
> Untuk: Waiter · Diperbarui 2026-10-13. Dokumen ini dibuat otomatis dari `src/lib/role-guides/` (`npm run docs:guides`) — ubah di sana, bukan di sini.

## 1. Mulai kerja

1. Login dengan akun kurir. Layar pertama adalah Kurir (Antaran saya).
2. Absen masuk di menu Absensi (PIN, selfie, GPS).
3. Tekan Siap antar → status Tersedia (hijau). Istirahat = Offline, Anda tidak menerima pesanan.
4. Izinkan lokasi (GPS) dan notifikasi di HP. Lokasi hanya dibagikan saat pesanan sedang diantar.

## 2. Mendapat pesanan

1. Ditugaskan kasir: muncul notifikasi Antaran baru di HP.
2. Ambil sendiri: di daftar Siap antar · ambil sendiri, tekan Ambil (hanya saat status Tersedia).
3. Satu kurir membawa satu antaran. Selesaikan dulu sebelum mengambil pesanan berikutnya.
4. Pesanan delivery selalu sudah lunas (QRIS). Kurir tidak menagih uang.

## 3. Mengantar

1. Tunggu sampai badge Produksi menunjukkan semua siap, lalu tekan Ambil pesanan di kasir.
   - **Penting:** Tombol Ambil pesanan terkunci selama Bar/Dapur masih membuat pesanan.
2. Cek isi pesanan, alamat, dan catatan. Pakai tombol Rute (peta), WA, atau Telepon untuk menghubungi pelanggan.
3. Tekan Mulai antar. GPS terkirim otomatis kira-kira tiap 15 detik (badge GPS terkirim hh:mm).
4. Sampai di tujuan: tekan Ambil foto bukti terkirim, foto pesanan diterima pelanggan.
5. Tekan Sudah sampai. GPS berhenti dan pesanan pindah ke Selesai diantar.

**Tanya jawab**

- **Kasir mengganti kurir?** Hanya bisa sebelum pesanan diambil. Setelah Ambil pesanan, pesanan tetap milik Anda sampai selesai.
- **Pesanan dibatalkan saat di jalan?** Hubungi kasir. Status Anda otomatis kembali Tersedia setelah order dibatalkan.

## 4. Selesai kerja

1. Pastikan tidak ada antaran yang masih berjalan, lalu tekan Istirahat.
2. Absen pulang di menu Absensi, lalu logout.
