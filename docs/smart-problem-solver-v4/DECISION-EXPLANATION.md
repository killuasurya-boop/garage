# AYA Smart Problem Solver V4 — Penjelasan Keputusan

Setiap laporan memuat: **Apa masalahnya** · **Fakta terverifikasi** (sumber, angka, waktu) · **Dugaan** dengan tingkat dukungan
data dan cara membuktikan · **Belum diketahui** (sumber gagal + ref, hasil terpotong, waktu data tidak tersedia) ·
**Akar masalah** (selalu "belum pasti" kecuali ada dugaan didukung; tanpa bukti = NEED_REVIEW) · **Dampak** per domain ·
**2–3 opsi** + risiko R0–R3 + konsekuensi · **⭐ Rekomendasi** · **Eksekusi** `BELUM_DILAKUKAN` · **Hasil** `BELUM_ADA` sampai
verifikasi · **Bukti & audit trail** (linimasa kasus).

Aturan bahasa: korelasi ≠ sebab; alert risiko = prioritas pemeriksaan, bukan tuduhan; "ACC/jalankan semua" tidak
mengubah apa pun; angka tidak dikarang (tidak ada data = tidak ada fakta).
