02Pilih CRM yang Cocok

Untuk franchise sales dengan ~50–200 lead/bulan, kamu tidak butuh CRM enterprise seperti Salesforce. Pilih yang ringan, gratis, mudah dipakai tim non-tech.

Notion

★ RECOMMENDED

Database flexible, view kanban/calendar/table, sharing mudah, sudah familiar untuk kebanyakan tim. Free tier cukup besar.

  • Free unlimited (untuk personal/small team)
  • UI familiar, drag-and-drop
  • Multiple view (table, board, calendar, gallery)
  • Bisa di-share ke tim sales tanpa license tambahan
  • Bukan CRM specialized — kurang reporting bawaan
// Cost: Free · Setup: 30 menit

Airtable

ALTERNATIVE

Lebih powerful untuk relational data (lead ↔ outlet ↔ kontrak). UI seperti spreadsheet++. Bagus untuk yang familiar dengan Excel.

  • Relational database (mirip database asli)
  • 1.000 records free per base
  • Automation built-in
  • UI sedikit lebih steep learning curve
  • $10–20/user/bulan untuk team plan
// Cost: Free 1K records / $10/user

HubSpot Free

PROPER CRM

Specialized CRM dengan pipeline, deal stage, email tracking. Cocok kalau tim sales kamu >3 orang dan butuh disiplin process.

  • Real CRM — pipeline visual, deal stages
  • Free unlimited contacts
  • Email tracking built-in (open, click)
  • Free tier limited (1.000 contacts active)
  • Upgrade Starter $20/bulan
// Cost: Free / $20/m Starter

Google Sheets

MINIMAL

Paling sederhana. Cocok untuk MVP <30 lead/bulan. Tidak ada otomasi, tapi 100% gratis dan familiar.

  • 100% gratis selamanya
  • Familiar untuk semua orang
  • Bisa di-link via Apps Script ke form
  • No automation native
  • Susah scale >100 lead
// Cost: Free · Setup: 10 menit
// REKOMENDASI

Untuk batch 1 (3 bulan pertama): Notion + Make.com. Murah, cepat setup, fleksibel. Migrasi ke HubSpot atau Airtable nanti kalau tim sudah >5 orang.

04Modifikasi Form Submit

Ubah handler di unduh-brosur.html dan konsultasi.html agar POST data ke Make.com webhook SEBELUM redirect ke WhatsApp. Lead masuk database otomatis, lalu user lanjut chat.

// Ganti URL ini dengan webhook URL dari Make.com
const WEBHOOK_URL = 'https://hook.eu1.make.com/your-webhook-id';

async function submitToCRM(data) {
  // Add UTM tracking
  const utm = JSON.parse(sessionStorage.getItem('garage_utm') || '{}');

  const payload = {
    ...data,
    ...utm,
    source: utm.utm_source || 'organic',
    status: 'New',
    tahap: 'Inquiry',
    inquiry_date: new Date().toISOString(),
    user_agent: navigator.userAgent,
    referrer: document.referrer || 'direct',
  };

  try {
    await fetch(WEBHOOK_URL, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(payload),
    });
    console.log('[CRM] Lead synced', payload);
  } catch (err) {
    // Fail silently — jangan blokir user dari lanjut ke WA
    console.error('[CRM] Sync failed (continuing)', err);
  }
}

07Apps Script untuk Google Sheets (Alternative Minimal)

Kalau pilih path minimal (Google Sheets only), pakai Apps Script untuk auto-tambah row dari form submission.

// Deploy as Web App, public access, anyone can access
function doPost(e) {
  try {
    const data = JSON.parse(e.postData.contents);
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('Leads');

    sheet.appendRow([
      new Date(),                  // Timestamp
      data.nama || '',
      data.hp || '',
      data.email || '',
      data.kota || '',
      data.paket || '',
      data.source || 'organic',
      data.utm_campaign || '',
      'New',                       // Status default
      'Inquiry',                   // Tahap default
      data.notes || '',
    ]);

    // Optional: send email notif
    MailApp.sendEmail({
      to: 'franchise@garagecoffee.id',
      subject: '🚨 Lead Baru: ' + data.nama,
      htmlBody: `<p><strong>Nama:</strong> ${data.nama}<br>
                 <strong>Kota:</strong> ${data.kota}<br>
                 <strong>Paket:</strong> ${data.paket}<br>
                 <strong>WA:</strong> <a href="https://wa.me/${data.hp.replace(/\D/g,'')}">Chat Sekarang</a></p>`
    });

    return ContentService.createTextOutput(JSON.stringify({ ok: true })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ ok: false, error: err.message })).setMimeType(ContentService.MimeType.JSON);
  }
}

08Auto-Tag Source dari UTM

Make.com bisa parsing UTM otomatis dan set Source field dengan logic ini:

// Logic untuk auto-tag Source di Make.com
function determineSource(utm_source, referrer) {
  const map = {
    'meta':     'Meta Ads',
    'facebook': 'Meta Ads',
    'fb':       'Meta Ads',
    'instagram':'Meta Ads',
    'ig':       'Meta Ads',
    'tiktok':   'TikTok Ads',
    'tt':       'TikTok Ads',
    'google':   'Google Ads',
    'gads':     'Google Ads',
    'youtube':  'YouTube',
  };

  // Priority 1: explicit UTM
  if (utm_source && map[utm_source.toLowerCase()]) {
    return map[utm_source.toLowerCase()];
  }

  // Priority 2: referrer
  if (referrer) {
    if (referrer.includes('google.')) return 'Google Organic';
    if (referrer.includes('facebook.com') || referrer.includes('instagram.com')) return 'Meta Organic';
    if (referrer.includes('tiktok.com')) return 'TikTok Organic';
  }

  return 'Direct';
}
